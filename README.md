# Homebrew Tap for Orbit

Official Homebrew tap for [Orbit](https://github.com/ziuus/orbit-tui) — the keyboard-driven terminal workspace and aesthetic system dashboard.

## Installation

```bash
brew tap ziuus/orbit
brew install orbit
```

Or install directly in one step:

```bash
brew install ziuus/orbit/orbit
```

## Update

```bash
brew upgrade orbit
```
